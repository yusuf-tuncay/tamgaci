# Tamgaci Hızlı Başlangıç Kılavuzu

Bu kılavuz, Tamgaci uygulamasını hızlı bir şekilde kullanmaya başlamanız için gerekli adımları içerir.

## 🚀 5 Dakikada Başlayın

### 1. Hesap Oluşturun (1 dakika)

1. Uygulamayı açın
2. "Kayıt Ol" butonuna tıklayın
3. E-posta adresinizi girin
4. Güçlü bir şifre oluşturun
5. "Hesap Oluştur" butonuna tıklayın
6. E-posta adresinize gelen doğrulama linkine tıklayın

### 2. İlk Müşterinizi Ekleyin (1 dakika)

1. Ana menüden "Müşteriler" seçeneğine tıklayın
2. "Yeni Müşteri" butonuna tıklayın
3. Aşağıdaki bilgileri doldurun:
   - **Ad/Unvan**: Test Müşteri
   - **E-posta**: test@example.com
   - **Telefon**: +905551234567
   - **Adres**: Test Adres
4. "Kaydet" butonuna tıklayın

### 3. İlk Ürününüzü Ekleyin (1 dakika)

1. Ana menüden "Ürünler" seçeneğine tıklayın
2. "Yeni Ürün" butonuna tıklayın
3. Aşağıdaki bilgileri doldurun:
   - **Ürün Kodu**: TEST001
   - **Ürün Adı**: Test Ürün
   - **Kategori**: Test Kategori
   - **Birim**: Adet
   - **Alış Fiyatı**: 50.00
   - **Satış Fiyatı**: 100.00
   - **Stok Miktarı**: 100
   - **Minimum Stok**: 10
4. "Kaydet" butonuna tıklayın

### 4. İlk Satışınızı Yapın (1 dakika)

1. Ana menüden "Satışlar" seçeneğine tıklayın
2. "Yeni Satış" butonuna tıklayın
3. Aşağıdaki bilgileri doldurun:
   - **Müşteri**: Test Müşteri
   - **Tarih**: Bugünün tarihi
   - **Ürün**: Test Ürün
   - **Miktar**: 5
   - **Fiyat**: 100.00 (otomatik gelecek)
4. "Kaydet" butonuna tıklayın

### 5. Dashboard'u İnceleyin (1 dakika)

1. Ana sayfaya dönün
2. Dashboard'da şunları göreceksiniz:
   - Toplam Satış: 500.00 TL
   - Toplam Müşteri: 1
   - Toplam Ürün: 1
   - Stok Seviyesi: 95 adet

## 🎯 Temel İşlemler

### Müşteri Yönetimi

#### Hızlı Müşteri Ekleme
```
Müşteriler → Yeni Müşteri → Bilgileri Doldur → Kaydet
```

#### Müşteri Arama
```
Müşteriler → Arama Çubuğu → Müşteri Adı Yaz → Enter
```

#### Müşteri Düzenleme
```
Müşteriler → Müşteriye Tıkla → Düzenle → Değişiklikleri Yap → Kaydet
```

### Ürün Yönetimi

#### Hızlı Ürün Ekleme
```
Ürünler → Yeni Ürün → Bilgileri Doldur → Kaydet
```

#### Stok Güncelleme
```
Ürünler → Ürüne Tıkla → Stok Güncelle → Miktar Gir → Kaydet
```

#### Düşük Stok Kontrolü
```
Dashboard → Düşük Stok Ürünleri → Ürün Listesi
```

### Satış İşlemleri

#### Hızlı Satış
```
Satışlar → Yeni Satış → Müşteri Seç → Ürün Ekle → Kaydet
```

#### Satış Listesi
```
Satışlar → Tarih Filtresi → Müşteri Filtresi → Listele
```

#### Tahsilat Ekleme
```
Satışlar → Satışa Tıkla → Tahsilat Ekle → Tutar Gir → Kaydet
```

### Alış İşlemleri

#### Hızlı Alış
```
Alışlar → Yeni Alış → Tedarikçi Seç → Ürün Ekle → Kaydet
```

#### Stok Artırma
```
Alışlar → Alışa Tıkla → Stok Hareketleri → Giriş Hareketi
```

## 📊 Hızlı Raporlar

### Günlük Satış Raporu
```
Raporlar → Satış Raporları → Bugün → Görüntüle
```

### Stok Durumu
```
Raporlar → Stok Raporları → Mevcut Stok → Görüntüle
```

### Müşteri Bakiyeleri
```
Raporlar → Finansal Raporlar → Bakiye Raporu → Görüntüle
```

## 🔧 Hızlı Ayarlar

### Şirket Bilgileri
```
Ayarlar → Genel Ayarlar → Şirket Bilgileri → Düzenle → Kaydet
```

### Para Birimi
```
Ayarlar → Genel Ayarlar → Para Birimi → TL/USD/EUR → Kaydet
```

### Bildirimler
```
Ayarlar → Bildirim Ayarları → Düşük Stok Uyarısı → Aktif/Pasif
```

## 💡 İpuçları

### Verimlilik İpuçları

1. **Kısayol Tuşları**
   - `Ctrl + N`: Yeni kayıt
   - `Ctrl + S`: Kaydet
   - `Ctrl + F`: Arama
   - `Ctrl + P`: Yazdır

2. **Hızlı Arama**
   - Müşteri adı, telefon veya e-posta ile arama
   - Ürün kodu veya adı ile arama
   - Fatura numarası ile arama

3. **Toplu İşlemler**
   - Çoklu müşteri seçimi
   - Toplu e-posta gönderimi
   - Toplu fiyat güncelleme

### Güvenlik İpuçları

1. **Şifre Güvenliği**
   - En az 8 karakter
   - Büyük/küçük harf, sayı ve özel karakter
   - Düzenli şifre değiştirme

2. **Veri Yedekleme**
   - Haftalık Excel yedekleme
   - Aylık PDF rapor yedekleme
   - Kritik verilerin manuel yedeklenmesi

3. **Erişim Kontrolü**
   - Güçlü şifre kullanımı
   - Düzenli giriş kontrolü
   - Şüpheli aktivite takibi
