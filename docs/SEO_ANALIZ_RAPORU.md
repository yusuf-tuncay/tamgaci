## ⚠️ İYİLEŞTİRME ÖNERİLERİ

### 1. Open Graph Görseli (ÖNEMLİ) 🔴

**Mevcut:** 256x256px  
**Önerilen:** 1200x630px

**Neden Önemli:**
- Facebook, LinkedIn, WhatsApp'ta link paylaşılınca görünen büyük görsel
- Profesyonel görünüm için kritik
- Daha fazla tıklanma oranı

**Yapılması Gereken:**
1. 1200x630px boyutunda görsel tasarlayın
2. Logo + marka rengi + tagline içermeli
3. `og-image-1200x630.png` olarak kaydedin
4. `web/index.html`'de URL güncellemesi yapılacak

### 2. Twitter Card Görseli 🟡

**Mevcut:** 256x256px (summary_large_image kullanılıyor ama görsel küçük)  
**Önerilen:** 1200x675px veya 1200x1200px

**Not:** summary_large_image kullanılıyor, görsel büyütülürse daha etkili olur.

### 3. Blog Sayfası İçin Structured Data 🔵

**Önerilen:** Article ve BreadcrumbList schema

Blog yazıları için:
- Article schema (her blog yazısı için)
- BreadcrumbList schema (navigasyon için)
- ImageObject schema (blog görselleri için)

### 4. FAQ Sayfası İçin Structured Data 🔵

**Önerilen:** FAQPage schema

FAQ sayfası için:
- FAQPage schema eklendiğinde Google'da rich snippets görünebilir
- Sorular ve cevaplar doğrudan arama sonuçlarında görünebilir

### 5. Google Search Console 🔵

**Önerilen:**
1. Google Search Console'a site ekleyin
2. Sitemap'i Google'a gönderin
3. Indexing durumunu takip edin
4. Core Web Vitals kontrol edin

### 6. Google Analytics 🔵

**Önerilen:**
- Google Analytics 4 kurulumu
- Goal tracking (form submissions, downloads)
- Conversion tracking
